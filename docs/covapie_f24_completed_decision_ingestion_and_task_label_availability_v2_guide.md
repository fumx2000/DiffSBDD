# CovaPIE F24 source-binding successor V2

This thin additive successor changes only active filesystem acceptance for the
published F24 V1 completed-decision ingestion. Exact bytes and SHA256, B1
filesystem security, and the frozen executable class replace live equality to
the historical numeric POSIX mode. The eight historical `0664` values remain
provenance metadata; all eight sources, including both Python validators, are
expected to be non-executable.

The public API is limited to `F24SourceBindingV2Error`,
`load_frozen_f24_authority_v2`, and
`verify_published_f24_v1_projection_v2`. It has no materialization, mutation,
cache, registry, or validator-execution API. Every authority byte is consumed
from `verify_bound_source_v2`; the original formal-validator path is never
executed or reopened after binding.

The successor binds and exercises both published predecessors: OZJ V2 for the
latest ingestion architecture and YUN V2 for DIRECT plus INCLUDE semantics.
Historical OZJ/YUN V1 provenance records remain unchanged in the reconstructed
F24 V1 manifest.

F24 science is unchanged. The Exact4 events are the 3V4X CYS:111- SG to F24 C8
observations. D4 remains `REVISE_ROLE_PARTITION`, D5 remains `INCLUDE`, and no
machine candidate is selected. The chemical beta-lactone core
`[C1,C2,C8,O2,O6]` remains intentionally distinct from the canonical warhead
role region `[C1,C2,C4,C8,O2,O5,O6]`; C4/O5 are role-region atoms, not asserted
chemical-core atoms.

The role profile remains `DIRECT_ATTACHMENT_OPTIONAL_LINKER_V1`, with an empty
linker and C5--C2 scaffold/warhead boundary. The global canonical vocabulary is
the exact five tasks A, B, B2, B3, and C, while only task IDs `[0,3,4]` are
structurally applicable to F24. INCLUDE creates a future admission candidate,
not formal admission, materialization, runtime usability, or training
authorization.

The published F24 V1 snapshot, matrix, summary, and manifest are verified
in-memory and are never regenerated. The historical F24 prior census remains
104 positive, 105 relevant, 40 INCLUDE, 64 EXCLUDE, 23 future candidates, and
104 pair/role authorities. The checker separately binds the current published
2A2 census and requires 112 positive, 113 relevant, 44 INCLUDE, 68 EXCLUDE, 27
future candidates, 112 pair/role authorities, and Exact5 counts
`A=112,B=52,B2=52,B3=112,C=112`.

This step does not start 2A2 V2, integration, I12, model execution, training,
or parameter updates. A feature-semantics audit remains mandatory before any
formal training; Step12D remains only a smoke legality check, not the final
training-feature contract.
